Part I. Multiple Choice

1. What type of routing protocol is OSPF?
Answer: C – Link-state
Explanation:
Open Shortest Path First (OSPF) is an Interior Gateway Protocol (IGP) that relies on the link-state routing algorithm to create a complete topological map of the network.
2. What does OSPF use to uniquely identify an OSPF router?
Answer: C – Router ID
Explanation:
In an OSPF domain, every router requires a unique 32-bit identifier called a Router ID to uniquely identify it within the network topology.
3. Which OSPF packet is used to discover neighbors and establish neighbor adjacencies?
Answer: D – Hello
Explanation:
The OSPF Hello packet is sent periodically out of all OSPF-enabled interfaces to discover other OSPF routers and establish/maintain neighbor adjacencies.
4. Which OSPF packet contains link-state advertisements?
Answer: D – Link-State Update
Explanation:
Link-State Update (LSU) packets are used to reply to Link-State Requests and to announce new information. They contain one or multiple Link-State Advertisements (LSAs).
5. What is the purpose of the OSPF Hello packet?
Answer: B – Discover neighbors and establish adjacencies
Explanation:
Hello packets are explicitly designed to find neighboring routers on the same network segment and ensure bi-directional communication to form an adjacency.
6. Which security principle ensures that only authorized users can access information?
Answer: C – Confidentiality
Explanation:
Confidentiality ensures that sensitive data is kept private and is not disclosed to unauthorized individuals, programs, or processes.
7. Which security principle ensures that data has not been altered without authorization?
Answer: D – Integrity
Explanation:
Integrity guarantees that information is accurate, complete, and has not been modified or corrupted by unauthorized parties.
8. Which security principle ensures that authorized users can access information when needed?
Answer: C – Availability
Explanation:
Availability ensures that network systems, data, and applications are accessible and operational for authorized users whenever required.
9. What is a firewall primarily used for?
Answer: A – Controlling and filtering network traffic
Explanation:
A firewall is a network security device that monitors incoming and outgoing network traffic and decides whether to allow or block specific traffic based on a defined set of security rules.
10. Why is network security implemented in multiple layers?
Answer: D – To provide multiple levels of protection against different threats
Explanation:
This is known as "Defense in Depth." If an attacker bypasses one security layer, subsequent layers provide backup protection, minimizing the overall risk.
11. An organization wants to protect its network from both external attackers and internal misuse. Which approach would provide the strongest protection?
Answer: D – Use multiple security controls and apply security at different layers
Explanation:
Relying on a single security mechanism leaves vulnerabilities. Layered security (Defense in Depth) ensures protection from diverse attack vectors, both internal and external.
12. What is an asset in an organization?
Answer: B – Anything of value to the organization
Explanation:
In cybersecurity, an asset is any physical or digital entity (data, hardware, software, personnel) that has value to the organization and needs protection.
13. This protocol provides a secure remote access connection to network devices.
Answer: B – SSH
Explanation:
Secure Shell (SSH) is a cryptographic network protocol that provides a secure, encrypted alternative to unencrypted protocols like Telnet for remote administration.
14. Which type of cyberattack occurs when an attacker secretly intercepts and alters communication between two parties who believe they are communicating directly with each other?
Answer: C – Man-in-the-Middle attack
Explanation:
In a Man-in-the-Middle (MitM) attack, the perpetrator inserts themselves into the communication channel to eavesdrop on or manipulate the traffic.
15. Which type of cyberattack uses a trial-and-error method to guess login credentials, encryption keys, or other sensitive data by systematically trying all possible combinations?
Answer: B – Brute-Force Attack
Explanation:
A brute-force attack involves an automated script or tool attempting every possible combination of a password or key until the correct one is discovered.
16. Which type of cyberattack attempts to trick individuals into revealing sensitive information, such as usernames, passwords, credit card numbers, or other personal data?
Answer: C – Phishing Attack
Explanation:
Phishing uses social engineering (typically via deceptive emails or websites) to manipulate users into voluntarily giving up confidential information.
17. Which type of hackers are ethical hackers who use their programming and technical skills for good, ethical, and legal purposes?
Answer: C – White Hat Hackers
Explanation:
White hat hackers are authorized security professionals who seek out vulnerabilities to help organizations patch security flaws before malicious attackers can exploit them.
18. Which type of hackers are unethical criminals who compromise computer and network security for personal gain or malicious purposes, such as attacking networks?
Answer: C – Black Hat Hackers
Explanation:
Black hat hackers illegally bypass security protocols for financial gain, data theft, or sheer malicious disruption.
19. What is the wildcard mask for the subnet mask 255.255.255.192?
Answer: B – 0.0.0.63
Explanation:
The wildcard mask is found by subtracting the subnet mask from the global broadcast mask (255.255.255.255). Step-by-step: Step 1: Write down the global broadcast mask: 255.255.255.255 Step 2: Write down the given subnet mask: 255.255.255.192 Step 3: Subtract octet by octet: (255-255=0), (255-255=0), (255-255=0), (255-192=63) Final result: 0.0.0.63
20. A network uses the subnet mask /27. What is its corresponding wildcard mask?
Answer: C – 0.0.0.31
Explanation:
A /27 prefix converts to the decimal subnet mask 255.255.255.224. Subtracting this from 255.255.255.255 gives the wildcard mask. Step-by-step: Step 1: Convert /27 to dotted decimal: 255.255.255.224 Step 2: Write down the global broadcast mask: 255.255.255.255 Step 3: Subtract the subnet mask: 255.255.255.255 - 255.255.255.224 Final result: 0.0.0.31
21. What is the wildcard mask for the subnet mask /22?
Answer: C – 0.0.3.255
Explanation:
A /22 prefix converts to the decimal subnet mask 255.255.252.0. Step-by-step: Step 1: Convert /22 to dotted decimal: 255.255.252.0 Step 2: Write down the global broadcast mask: 255.255.255.255 Step 3: Subtract the subnet mask: (255-255=0), (255-255=0), (255-252=3), (255-0=255) Final result: 0.0.3.255
22. Which OSPF network type requires a Designated Router and Backup Designated Router?
Answer: B – Multiaccess
Explanation:
In multiaccess networks (like Ethernet), a DR and BDR are elected to reduce OSPF traffic and the number of adjacencies that need to be maintained.
23. What is the primary role of the Designated Router in a multiaccess OSPF network?
Answer: A – Collect and distribute LSAs
Explanation:
The DR acts as a central collection and distribution point for Link-State Advertisements (LSAs) on the multiaccess network, reducing network overhead.
24. Why is a BDR elected in a multiaccess OSPF network?
Answer: A – To take over the DR role if the DR fails
Explanation:
The Backup Designated Router maintains full adjacencies and listens to routing updates so it can immediately become the DR if the current DR goes offline.
25. Which statement best describes an LSU and an LSA?
Answer: A – An LSU can contain one or more LSAs
Explanation:
A Link-State Update (LSU) is a packet type that acts as an envelope. It can carry one or multiple Link-State Advertisements (LSAs) inside it.
26. Why must neighboring OSPF routers have matching Hello parameters?
Answer: A – To establish an OSPF adjacency
Explanation:
For two OSPF routers to form a neighbor relationship, their Hello interval, Dead interval, Area ID, and authentication settings must match exactly.
27. A network administrator wants to identify a specific OSPF router in the OSPF domain. Which value should be examined?
Answer: C – Router ID
Explanation:
The 32-bit Router ID uniquely identifies each router operating within the OSPF routing domain.
28. A router has a router ID of 3.3.3.3, while the other routers have IDs of 1.1.1.1 and 2.2.2.2. In a multiaccess network with equal priorities, which router would normally be elected DR?
Answer: C – Router 3.3.3.3
Explanation:
If OSPF router priorities are equal (default is 1), the router with the highest Router ID is elected as the Designated Router (DR).
29. R1 and R2 are connected through a point-to-point link. The administrator expects a DR and BDR election, but none occurs. Is this behavior expected?
Answer: C – Yes, point-to-point OSPF networks do not require a DR/BDR election
Explanation:
In a point-to-point link, there are only two routers communicating. There is no need for a DR or BDR to manage overhead, so the election is bypassed.
30. A network administrator changes the router priority of one OSPF router on a multiaccess network. What is the primary reason for making this change?
Answer: C – To influence the DR/BDR election
Explanation:
Router priority (0-255) is the primary tiebreaker in OSPF elections. Setting a priority higher than other routers ensures it becomes the DR.
31. Which command enables OSPFv2 using router configuration mode?
Answer: C – router ospf process-id
Explanation:
This command initializes the OSPF routing process on a Cisco router and moves the CLI context into router configuration mode. Step-by-step: Step 1: Enter privileged EXEC mode. Step 2: Type configure terminal to enter global configuration mode. Step 3: Type router ospf [process-id] to enable the process. Final command: router ospf process-id
32. What is the valid range of the OSPF process ID?
Answer: D – 1-65,535
Explanation:
When configuring OSPF globally, the locally significant process ID must fall within the range of 1 to 65,535.
33. Which command is used to explicitly configure an OSPF router ID?
Answer: D – router-id rid
Explanation:
Within OSPF router configuration mode, the router-id [ip-address] command is used to statically assign the Router ID. Step-by-step: Step 1: Enter global configuration mode (configure terminal). Step 2: Enter OSPF configuration mode (router ospf [process-id]). Step 3: Type router-id [ip-address]. Final command: router-id rid
34. What is the first preference in the OSPF router ID selection order?
Answer: D – Explicitly configured router ID
Explanation:
OSPF will always prefer a manually configured Router ID using the router-id command over any active physical or loopback IP addresses.
35. What is the second method used by Cisco IOS to select the router ID?
Answer: B – Highest IPv4 address of a configured loopback interface
Explanation:
If no explicit Router ID is configured, OSPF defaults to the highest IP address configured on an active loopback interface.
36. Which command enables OSPF on an interface by using the interface configuration mode?
Answer: C – ip ospf process-id area area-id
Explanation:
Instead of using the network command in router mode, OSPFv2 can be enabled directly on a specific interface using this interface-level command. Step-by-step: Step 1: Enter global configuration mode (configure terminal). Step 2: Enter interface configuration mode (interface [interface-id]). Step 3: Apply OSPF directly to the interface. Final command: ip ospf process-id area area-id
37. Which OSPF area is used in a single-area OSPF configuration?
Answer: D – Area 0
Explanation:
Area 0 is the backbone area. In a single-area OSPF design, all routers must be placed in Area 0 to ensure proper routing functionality.
38. Which command is used to suppress OSPF routing messages from an interface while still advertising its network?
Answer: C – passive-interface
Explanation:
The passive-interface command prevents OSPF Hello packets from being sent out an interface, stopping adjacencies from forming on that port, but the network itself is still advertised to other routers. Step-by-step: Step 1: Enter OSPF router configuration mode (router ospf [process-id]). Step 2: Suppress OSPF messages on the target interface. Final command: passive-interface [interface-id]
39. Which command displays OSPF neighbor information?
Answer: C – show ip ospf neighbor
Explanation:
This standard EXEC command verifies that an OSPF router has successfully formed adjacencies with its neighboring routers and displays their states. Step-by-step: Step 1: Ensure you are in privileged EXEC mode (or use do in config mode). Step 2: Enter the verification command. Final command: show ip ospf neighbor
40. Which command provides detailed information about an OSPF-enabled interface?
Answer: B – show ip ospf interface
Explanation:
This command reveals OSPF-specific parameters applied to an interface, including its Area ID, Process ID, Cost, state (DR/BDR), and timer intervals. Step-by-step: Step 1: Ensure you are in privileged EXEC mode. Step 2: Enter the verification command. Final command: show ip ospf interface
41. What does a wildcard mask of 0.0.0.0 accomplish when used with an OSPF network command?
Answer: C – It matches one exact IPv4 address
Explanation:
In a wildcard mask, a "0" means the bit must match exactly. Therefore, a mask of 0.0.0.0 dictates that all 32 bits must match the specified IP address perfectly, restricting OSPF to that single specific interface address.
42. An administrator wants to configure OSPF process 10 on R1. Which command should be entered?
Answer: C – router ospf 10
Explanation:
This initiates the OSPF routing engine and assigns it a locally significant process ID of 10. Step-by-step: Step 1: Enter global configuration mode (configure terminal). Step 2: Initialize the OSPF process. Final command: router ospf 10
43. R1 has an interface with IP address 10.1.1.5. The administrator wants to enable OSPF only on that exact interface using the network command. Which command is appropriate?
Answer: C – network 10.1.1.5 0.0.0.0 area 0
Explanation:
To match the exact IP address, the network command must specify the IP with a 0.0.0.0 wildcard mask. Step-by-step: Step 1: Enter OSPF router configuration mode (router ospf [process-id]). Step 2: Enter the exact IP and wildcard mask. Final command: network 10.1.1.5 0.0.0.0 area 0
44. An administrator wants to enable OSPF directly on GigabitEthernet 0/0/0 using process 10 in Area 0. Which command should be used?
Answer: C – ip ospf 10 area 0
Explanation:
This is the correct interface-level configuration syntax to enable OSPF without using the global network command. Step-by-step: Step 1: Enter global configuration mode (configure terminal). Step 2: Access the specific interface (interface GigabitEthernet 0/0/0). Step 3: Enable OSPF on the interface directly. Final command: ip ospf 10 area 0
45. Which three goals make up the CIA Triad of network security?
Answer: B – Confidentiality, Integrity, Availability
Explanation:
The CIA Triad is the foundational model in cybersecurity, designed to guide policies for information security within an organization.

Part II. True or False

1. Use the router-id rid router configuration mode command to manually assign a router ID.
Answer: TRUE
Explanation:
The router-id [ip-address] command inside OSPF configuration mode is the standard method for manually assigning a unique Router ID. Step-by-step: Step 1: Enter OSPF router config mode (router ospf [process-id]). Step 2: Assign the ID manually. Final command: router-id [ip-address]
2. When configuring single-area OSPFv2, the network command must be configured with the same area-id value on all routers.
Answer: TRUE
Explanation:
For routers to form adjacencies and share routing tables in a single-area setup, they must all be configured to belong to the exact same area (typically Area 0).
3. The basic syntax for the network command is ip ospf process-id area area-id.
Answer: FALSE
Explanation:
That syntax is used for interface-specific configuration mode. The basic syntax for the standard global network command is: network [network-address] [wildcard-mask] area [area-id].
4. Remove the network commands using the delete form of the command.
Answer: FALSE
Explanation:
In Cisco IOS, commands are negated or removed using the no keyword, not delete. Step-by-step: Step 1: Enter OSPF router configuration mode (router ospf [process-id]). Step 2: Prepend the no keyword to the exact network statement. Final command: no network [ip-address] [wildcard-mask] area [area-id]
5. OSPFv2 is enabled using the router ospf area-id command.
Answer: FALSE
Explanation:
OSPFv2 is initialized globally using the process ID, not the area ID. The correct command is router ospf process-id.
